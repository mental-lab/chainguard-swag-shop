Every Chainguard package ships with a signed SLSA provenance attestation — a cryptographically verifiable record of how, where, and when the package was built.

Hermetic Build

How to Switch — Drop-In Replacement

Switching to Chainguard Libraries requires a single config file change. Your existing requirements.txt and tooling work unchanged.

Option 1: pip.conf (recommended)

[global]
index-url = https://libraries.cgr.dev/python/
extra-index-url = https://pypi.org/simple/

All pip installs will prefer Chainguard-remediated packages automatically.

Option 2: make switch-cgr (this demo app)

make switch-cgr

Activates the pre-configured pip.conf in this project — instantly switches all Python package installs to Chainguard Libraries.

Option 3: Docker build-arg

docker build \
  --build-arg PIP_INDEX_URL=https://libraries.cgr.dev/python/ \
  -t myapp:latest .

No code changes required. Works with any Dockerfile that uses pip install.
