Vulnerability Details:
  • CWE-78: Command Injection
  • Risk: Critical
  • Impact: Remote code execution
Fix Recommendation:

Use input validation, sanitization, and avoid shell=True in subprocess calls. Use parameterized commands or safe alternatives.

🔒 Security Notes

This demo shows how user input can be injected into system commands. In a real attack, malicious users could:

  • Execute arbitrary commands
  • Access sensitive files
  • Install malware
  • Escalate privileges
