📁 Path Traversal Demo
Try these path traversal examples:
  • ../app.py
  • ../requirements.txt
  • ../README.md
  • sensitive_data.txt
  • admin_notes.txt
  • ../../etc/passwd
Vulnerability Details:
  • CWE-22: Path Traversal
  • Risk: High
  • Impact: Unauthorized file access
Fix Recommendation:

Validate and sanitize file paths. Use allowlists for permitted files and prevent directory traversal sequences.

🔒 Security Impact

Path traversal vulnerabilities can allow attackers to:

  • Read sensitive configuration files
  • Access source code
  • View system files
  • Discover application structure
  • Extract credentials and secrets
